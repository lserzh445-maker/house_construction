# Техническое задание для разработки сайта по строительству каркасных домов

## 📋 Структура документов

### 1. **TZ_Karkasnye_Doma_Polnoe.md** (Основной документ ТЗ)
Полное техническое задание из 12 разделов:

- **Раздел 1:** Анализ 5 конкурентных сайтов (сильные стороны и недостатки)
- **Раздел 2:** Архитектура сайта (карта сайта, структура меню, обязательные блоки)
- **Раздел 3:** Функциональные требования (фильтры, карточки, формы, калькулятор, отзывы, мессенджеры)
- **Раздел 4:** Требования к контенту (описания проектов, визуальный контент, блог)
- **Раздел 5:** UI/UX и дизайн (палитра, типография, компоненты, адаптивность)
- **Раздел 6:** Технические требования (tech stack, производительность, браузеры, безопасность)
- **Раздел 7:** Интеграции (CRM, финансирование, мессенджеры, аналитика)
- **Раздел 8:** SEO и маркетинг (on-page SEO, ключевые слова, linkbuilding, контент)
- **Раздел 9:** Безопасность (защита данных, защита от атак, регуляции)
- **Раздел 10:** Мобильная версия (UX, изображения, видео, производительность)
- **Раздел 11:** Производительность (метрики, кэширование, load testing)
- **Раздел 12:** План разработки (фазы, календарь, команда)

**Итоговое резюме:**
- Обязательный функционал (MVP)
- Опциональный функционал (Phase 2+)
- Ключевые KPI и метрики успеха
- Финальные рекомендации

## 🚀 Быстрый старт

### Шаг 1: Изучение (4 часа)
- Прочитайте README (вы здесь)
- Посмотрите ИТОГОВОЕ РЕЗЮМЕ в TZ_Karkasnye_Doma_Polnoe.md
- Изучите Раздел 2 (архитектура)

### Шаг 2: Планирование (1 день)
- Проведите встречу с командой
- Обсудите tech stack (Раздел 6.1)
- Уточните timeline (Раздел 12)
- Составьте backlog

### Шаг 3: Дизайн (2-3 недели)
- Дизайнер создает wireframes и UI Kit (Раздел 5)
- Скиньте прототип для утверждения

### Шаг 4: Разработка (6-8 недель)
- Backend и Frontend параллельно (Раздел 6)
- Интегрируйте CRM, аналитику (Раздел 7)
- Тестируйте производительность (Раздел 11)

### Шаг 5: Запуск (1-2 недели)
- Финальное тестирование (Раздел 12 - Фаза 4)
- Миграция данных
- Настройка SEO и аналитики (Раздел 8)
- Go-live

- Мощные системы фильтров

## 📱 Рекомендуемый tech stack

```
Frontend:  React.js + Next.js (SSR для SEO)
Backend:   Node.js (Express.js или Nest.js)
Database:  PostgreSQL + Redis
CDN:       Cloudflare или AWS CloudFront
CMS:       Contentful или Strapi (headless)
Hosting:   AWS или Google Cloud
Monitoring: Sentry + New Relic
```

**Почему не WordPress?** 
- Медленно на мобильных
- Сложно масштабировать
- Плохо с SEO

**Почему не 1C-Bitrix?**
- Дорого
- Специфичен для B2B
- Сложно с интеграциями
