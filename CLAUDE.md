# CLAUDE.md - Задание для Claude Code
## Разработка веб-сайта для компании, строящей каркасные дома

---

## 📋 КРАТКОЕ ОПИСАНИЕ ПРОЕКТА

**Название:** Сайт продажи и заказа каркасных домов  
**Целевая аудитория:** Люди, ищущие возможность быстро построить загородный дом  
**Бюджет:** Стандартный  
**Сроки:** 9 недель (2-2.5 месяца)  
**Команда:** 9 человек (PM, Designer, 2 Backend, 2 Frontend, DevOps, QA)

---

## 🎯 ОСНОВНЫЕ ЦЕЛИ

1. ✅ Создать **быстрый, удобный каталог** каркасных домов
2. ✅ **Максимизировать лиды** через множественные CTA
3. ✅ **Интегрировать мессенджеры** (WhatsApp, Telegram, Live chat)
4. ✅ **Встроить видеоконтент** из YouTube
5. ✅ **Оптимизировать для мобильных** (Lighthouse >85)
6. ✅ **Внедрить CRM** (Bitrix24) и аналитику (GA4, Яндекс.Метрика)
7. ✅ **SEO оптимизация** (структурированные данные, быстрая загрузка)

## 🔧 ТЕХНОЛОГИЧЕСКИЙ СТЕК

### Frontend

```
React.js + Next.js (SSR для SEO)
- State management: Redux или Zustand
- Styling: Tailwind CSS + Styled Components
- UI Library: Headless components (radix-ui)
- Forms: React Hook Form + Zod (валидация)
- HTTP Client: Axios или Fetch
- Animations: Framer Motion
- Build: Next.js built-in (Webpack)
```

### Backend

```
Node.js + Express.js (или Nest.js)
- Database: PostgreSQL 14+
- Caching: Redis
- Search: Elasticsearch или Algolia
- ORM: Prisma или TypeORM
- Validation: Joi или Zod
- Auth: JWT tokens
- Logging: Winston, Morgan
```

### CMS (опционально)

```
Headless CMS: Contentful, Strapi или Sanity.io
- Для управления проектами, статьями, отзывами
- API-driven подход
```

### Инфраструктура

```
Hosting:        AWS (EC2, RDS, S3) или Google Cloud
CDN:            Cloudflare или AWS CloudFront
Containers:     Docker
CI/CD:          GitHub Actions или GitLab CI
Monitoring:     Sentry (ошибки), New Relic (APM)
Backup:         AWS S3 или Google Cloud Storage
```

- Адаптивные изображения (srcset 1x, 2x, 3x)

- WebP (fallback на JPEG)

- Не автоplay (unless user explicitly clicked)

Performance:
- FCP < 1.5s
- LCP < 2.5s

## 💡 ФИНАЛЬНЫЕ РЕКОМЕНДАЦИИ

1. **Скорость загрузки – критична** 
   - Все конкуренты медленные на мобильных
   - Инвестируйте в CDN и оптимизацию изображений
   - Целевой Lighthouse >85

2. **Видеоконтент – дает результаты** 
   - Встройте YouTube видео в карточки проектов
   - Целевой контент: 350+ видео на YouTube (как Kolosov House)
   - Видео обзоры построенных домов дают социальное доказательство

3. **Мессенджеры – обязательны** 
   - WhatsApp и Telegram отсутствуют у всех конкурентов!
   - Это ваше преимущество
   - Live chat также критичен для современных пользователей

4. **Персонализация и рекомендации**
   - Покажите "похожие проекты" на карточке
   - Используйте историю просмотров для рекомендаций

5. **A/B тестирование**
   - Тестируйте текст CTA кнопок
   - Тестируйте цвета кнопок (зеленый vs оранжевый)
   - Даже 1% прирост конверсии = существенный рост лидов

6. **Build of trust**
   - Выберите 2-3 лучших проекта для показа на главной
   - Покажите процесс заказа пошагово (8 шагов)
   - Выставочный комплекс + экскурсии (если есть возможность)

7. **Региональность**
   - Если объекты в разных городах, создайте региональные версии
   - Локальное SEO важно (Google Maps, Яндекс.Карты)

8. **Контент – король**
   - Запустите блог с 20-50 статей
   - Публикуйте 2-4 новые статьи в месяц
   - Инвестируйте в SEO контент-маркетинг
